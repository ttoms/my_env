*rtl_align.txt*	SystemVerilog / Verilog RTL 代码对齐插件

==============================================================================
rtl_align.vim — SystemVerilog / Verilog RTL 代码对齐
==============================================================================

按统一列对齐规则格式化 RTL 代码。对齐幂等（重复执行结果不变）。

------------------------------------------------------------------------------
1. 命令						*rtl-align-commands*
------------------------------------------------------------------------------

:RtlAlign				对齐整个缓冲区。

						*rtl-align-map*
<leader>aa   (普通模式)		对齐整个缓冲区
<leader>aa   (可视模式)		对齐选中块（自动判定信号块 / 例化块）

------------------------------------------------------------------------------
2. 标记						*rtl-align-markers*
------------------------------------------------------------------------------

对齐依靠三个标记定位作用域：

	// @vlog-align	信号声明块（type / dims / name / ; 列对齐）
	// @inst		模块例化块（.port / (sig / ) 列对齐）
	// keep		跳过该行（行尾注释）

module 声明（parameter 列表 + port 列表）无需标记，自动对齐。

------------------------------------------------------------------------------
3. 对齐规则					*rtl-align-rules*
------------------------------------------------------------------------------

- 所有列左对齐；列起始位置 = 上一列结束 + 1 空格，向上取整到 4 的倍数
- packed 维度 [MSB:LSB] 拆两列：prefix（[MSB，左对齐）/ suffix（:LSB]，右对齐）
- 逗号行首：块内首项无逗号，其余项行首逗号（兼容行尾逗号输入，自动迁移）
- 纯注释行不参与对齐

------------------------------------------------------------------------------
4. 示例						*rtl-align-example*
------------------------------------------------------------------------------

对齐前:
    // @vlog-align
    logic [W-1:0] data;
    logic [7:0] cfg;
    wire clk_gated;

对齐后:
    // @vlog-align
    logic   [W-1:0]    data        ;
    logic   [7  :0]    cfg         ;
    wire                clk_gated   ;
